# VCET Calculator - Work Version

Dit is de werkversie van de VCET Calculator, gepubliceerd op:
**https://vcet-saldo.github.io/vcet-calculator-work/**

De main versie is beschikbaar op:
**https://vcetcalc.online/** (vcet-calculator repo met custom domain)

## Bestanden
- `index.html` - De main calculator pagina
- `fun.html` - Fun/easter egg pagina met grappige katten
- `manifest.json` - PWA-manifest
- `service-worker.js` - Offline cache
- `favicon.ico` - Browser icoontje
- `vcet-logo.png` - VCET logo

## Deployment
Deze repo is automatisch gelinkt aan GitHub Pages. Changes naar main branch worden direct gepubliceerd.
